The AI-era FinOps problem (10 min)

AI writes IaC in minutes. A wrong SKU runs for months. "Production-ready" to Copilot often means Premium plan + Geo-redundant SQL + Standard Redis — the exact defaults that go from $50/month to $5000/month.

Three cost signals you want on every repo:

  • Estimate — Infracost on every PR (seconds)
  • Actuals — Azure Cost Analysis (about a day behind)
  • Budget — Azure Budgets alerts when actuals cross a threshold

⭐ Takeaway

"Production-ready" is not a cost spec. If the spec does not say cheapest SKU that meets requirement X, Copilot will reach for Premium. Infracost on PR catches this before merge. Azure Budgets catches it 24 hours after it bills you.

Reusable line for every IaC spec:

Use the cheapest SKU/tier that meets the stated requirements. No premium, no autoscale, no geo-redundancy, no cross-region replication unless explicitly listed.
